# Execution plans

Use a plan for work spanning turns or needing durable decisions. The directory must match its status: `active/`, `completed/`, or `abandoned/`. `scripts/lint-docs.ts` enforces directories, status, and the headings below.

```md
# Plan title

Status: active
Owner: agent
Started: YYYY-MM-DD
Related docs: links

## Goal

## Acceptance criteria

## Current context

## Steps

- [ ] Work item

## Decisions

## Verification log

## Handoff notes
```

Keep progress/decisions current. On completion or abandonment, update status, record evidence/reason, and move the file. Promote durable project facts into the owning topic doc; completed plans retain historical evidence rather than current setup instructions.
